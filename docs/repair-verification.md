# CourseSchedule 修复与验证说明

日期：2026-10-01。修复已写入原项目。本次以 v1.2.42（versionCode 48）发布；以下功能验证在版本号调整前完成。

## 已修复

1. 学期外提醒：新增实际教学周判断。开学前和结束后不安排课程提醒、不保留正在上课通知，今日／周桌面组件不重复显示首周或末周课程。手动浏览课表保留原有周次范围。
2. 导入校验：JSON／CSV 错误记录显示位置，整批拒绝写入，避免静默漏课或修改星期。统一检查名称、星期、节次顺序、1–53 周、目标学期总周数及作息覆盖。CSV 支持 BOM、中文与带引号表头、转义引号和多行字段；JSON 示例完整输出默认字段。
3. 导入去重：文件、经典正方和河科大入口共用事务服务，跳过已有及同批重复课程，保留不同教师、地点、周次或周类型的安排。确认前切换学期会阻止写入；成功提示新增与重复数量。刷新组件后再返回主页。
4. Cookie：按名称、域名、路径合并或替换，保留其他认证 Cookie，按域名／路径／HTTPS 匹配请求，清除过期 Cookie 和退出后的认证数据。
5. 广播：内部提醒接收器不对外导出；单独的开机接收器只接受系统受保护的开机动作；未知动作不发送通知。提醒重排串行执行，避免并发取消与注册交错。
6. 维护：设置主文件从 1406 行拆为 287 行，导入主文件从 957 行拆为 205 行；外观、提醒、更新、各弹窗、平台操作、搜索、格式说明与文本导入各自独立。
7. 构建：修复 Gradle 启动脚本查找 Java 的逻辑，固定跨平台脚本换行，增加 Windows 的 WSL 构建入口 `scripts/build-wsl.ps1` 并验证可运行。复用本机已有 JDK 17 与 Android SDK，无需设置 Windows 全局 Java 环境。

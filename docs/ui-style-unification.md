# UI 风格统一说明

## 项目分析

项目是 Kotlin / Jetpack Compose Android 应用，使用 Material 3、Navigation Compose、Hilt 和 Room。课表主页是 `TimetableScreen`，其他页面包括课程编辑、课表导入、教务登录、设置、学期管理、作息管理和初始化引导。

主页已建立蓝色强调色、浅灰背景、紧凑信息密度及小圆角卡片的视觉方向。全局 `ScheduleTheme` 已提供明暗配色与字体，主要差异来自二级页面默认的 Material 标题栏、16dp 卡片圆角、分散的页面边距和部分手写字体尺寸。

## 本次调整

- 新增 `ui/theme/ScheduleStyle.kt`，集中管理 12dp 卡片圆角、12dp 内容边距及统一的 `ScheduleTopAppBar`。
- 全部 13 处二级页面标题栏使用 48dp 紧凑高度、16sp 标题、主题背景色和蓝色操作按钮，保留原有导航、保存及关闭行为。
- 设置分组、导入方式卡片、导入审核、学期与作息卡片和引导卡片统一复用卡片形状。
- 课程编辑、设置、导入、学期和作息管理的主要内容区域统一边距。
- 全局弹窗统一为主页课程详情使用的 22dp 圆角。
- 设置列表文字回归全局 bodyMedium / bodySmall 字号，避免 11.5sp 的独立覆盖。
- 主页引导卡片及全局 medium 形状也引用同一圆角定义，后续样式调整有共同入口。

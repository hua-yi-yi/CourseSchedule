- 学期:完整数据 → 已完成;名称空 / 日期 0 / 周数 0 或 54 → 待设置;无学期 → NO_SEMESTER。

## 二、需要真机/模拟器验证的验收用例

> 说明:本机为 Linux 构建环境,无 Android 模拟器图形界面,以下用例需在真机或模拟器上手动执行。

### 1. 新用户路径
- [ ] 全新安装 → 课表为空 → 点击任意空白格 → 出现「先完成课表设置」,学期/作息均为黄叹「待设置」。
- [ ] 点「学期」→ 进入学期菜单 → 新建学期(填名称、日期选择器选日期、总周数 18)→ 保存返回。
- [ ] 再点「作息时间」→ 进入作息菜单 → 选择作息方案 → 内置模板「夏季作息」→ 预览各节起止 → 「使用此方案」。
- [ ] 回到引导面板:两项都变绿勾「已完成」→「继续添加课程」可用 → 点击。
- [ ] 课程编辑页预填的星期 / 开始节次 / 起始周 = 最初点击的位置。

### 2. 老用户升级
- [ ] 用 v1.2.2 建好学期/课程/作息,覆盖安装 v1.2.3。
- [ ] 课程、学期、作息时间全部保留;学期与作息状态均为「已完成」,不出现待设置。
- [ ] 「我的方案」中出现「原有作息」,且为「当前使用」。

### 3. 取消与失败
- [ ] 编辑学期时修改内容后按返回 / 系统返回键 → 弹出「放弃未保存的修改?」→ 选「继续编辑」内容保留;选「放弃」数据不变。
- [ ] 保存失败(如总周数填 0)→ 保留输入、提示原因、不显示成功、状态不变绿。

### 4. 切换
- [ ] 选择另一学期并确认 → 课表课程与关联作息一起切换(若该学期绑定的是别的方案)。
- [ ] 切回原学期 → 恢复原作息。
- [ ] 切换到自定义方案后,原自定义方案仍在「我的方案」中可再次选择。

### 5. 共享方案
- [ ] 让两个学期都用同一个自定义方案 → 编辑该方案时出现「正被 2 个学期使用」提示与「另存为新方案」。
- [ ] 删除该方案 → 弹窗列出受影响学期;确认后相关学期回落到「原有作息」,课程仍在。

### 6. 覆盖性修复
- [ ] 方案缺少课程使用的节次 → 引导面板/总览页明确显示「缺少节次:第 X、Y 节」。
- [ ] 编辑方案补上缺失节次并保存 → 状态转为已完成。

### 7. 小组件与备份
- [ ] 修改课程 / 切换学期 / 切换作息 / 改节次时间后,今日课程与周课表小组件自动刷新。
- [ ] **多学期完整恢复(换手机场景)**:建立 3 个学期,各放不同课程并分别绑定不同作息方案 → 导出 → 在另一台设备(或清空数据后)恢复:
  - [ ] 3 个学期全部出现,名称/开学日期/总周数一致;
  - [ ] 每个学期的课程都回到自己的学期下(不串到当前学期);
  - [ ] 每个学期仍绑定原来的作息方案(自定义方案重建后仍可选中);
  - [ ] 当前学期与备份时一致;
  - [ ] 内置模板没有出现重复的「夏季作息 / 冬季作息」副本。
- [ ] **重复恢复同一备份两次** → 自定义方案数量不变(不出现多份同名方案),课程数一致;提示数量等于实际课程总数。
- [ ] 仅课程 JSON(旧格式)导入 → 仍只替换当前学期课程,且提示为「成功恢复 N 门课程(当前学期)」;完整备份提示为「(含全部学期)」。
- [ ] 用 v1.2.2 导出的旧备份(v1)恢复 → 正常还原,不报错。

### 8. 无障碍与深色模式
- [ ] 开启 TalkBack:状态徽标朗读为「已完成」/「待设置」。
- [ ] 深色模式下绿勾/黄叹与文字对比度可读(不依赖颜色单一表达)。
